# I18N · 国际化指南（0.16.1 新增）

> NovaI18n 服务单例：对标 Quasar Lang 插件（`$q.lang`）+ vue-i18n 语义，QML 语境裁定后的落地形态。
> 本文是使用文档；设计依据与基线事实见 `NovaI18n.qml` 头注释。

## 一、快速上手

```qml
import Nova.Services

// 绑定式翻译：locale 变化时自动重求值
Text { text: NovaI18n.t("confirm") }
Text { text: NovaI18n.t("selected", { n: 5 }) }   // 插值："已选 5 项"
Text { text: NovaI18n.tp("apple", 3) }             // 复数："3 apples"
```

```js
// 命令式切换（对标 $q.lang.set）
NovaI18n.setLocale("zh-CN")

// 运行时热注入词典（幂等覆盖，可增量）
NovaI18n.addBundle("de-DE", { confirm: "Bestätigen", cancel: "Abbrechen" })
NovaI18n.addPluralBundle("de-DE", { apple: { one: "{n} Apfel", other: "{n} Äpfel" } })
```

## 二、API 一览

| 成员 | 语义 | 对标 |
|---|---|---|
| `locale` / `isoName` | 当前 BCP-47 语言（如 `"zh-CN"`），可读写 | `$q.lang.isoName` |
| `setLocale(name)` | 切换全局 locale（同名幂等） | `$q.lang.set()` |
| `baseLang` | 主语言码（`"zh-TW"` → `"zh"`） | — |
| `isRtl` / `direction` | RTL 判定与方向（`"rtl"` / `"ltr"`） | `$q.lang.rtl` |
| `t(key, params)` | 词典翻译 + `{name}` 插值 | `$t()` |
| `tp(key, n, params)` | 复数翻译（自动选类别，`n` 注入 `{n}`） | `$tc()` / vue-i18n 选择式 |
| `pluralCategory(n)` | 当前语言下 n 的 CLDR 类别 | Intl.PluralRules |
| `addBundle / addPluralBundle` | 运行时热注入普通/复数词典包 | `$q.lang.props` 合并 |
| `formatNumber(n, decimals)` | 千分位分组 + 小数点（分隔符随 locale） | Intl.NumberFormat |
| `formatCurrency(n, decimals)` | 货币符号 + 数字（符号表随 locale） | Intl.NumberFormat currency |
| `formatDate(date, style)` | 日期时间本地化（style 或自定义 pattern） | Intl.DateTimeFormat |
| `formatRelative(date, now)` | 相对时间（复数联动 `dayAgo/monthAgo/yearAgo`） | Intl.RelativeTimeFormat |

## 三、内置词典与回落链

内置 **en-US / zh-CN** 完整词典（普通 + 复数），键位约定：

```text
confirm cancel submit save close search loading retry menu more expand collapse
prevPage nextPage firstPage lastPage selected({n}) itemsOf({n}) emptyText required
dayAgo({n}) monthAgo({n}) yearAgo({n})
```

**翻译查找链**（`t()`）：

1. locale 精确匹配的包（`zh-TW` → `zh-CN`，主语言码前缀回落）
2. → **en-US** 包（兜底）
3. → key 本身（显式暴露缺译，不静默）

**复数查找链**（`tp()`）：复数包 locale 精确 → 前缀回落 → 类别缺省回落 `other` → 普通词典 → key。

## 四、复数规则（CLDR 精简实现，零依赖）

不引 ICU（离线可用），JS 精简实现七语系卡片规则：

| 语言 | 类别 |
|---|---|
| zh / ja / ko / th / vi | 恒 `other` |
| en / de / es / fr / it… | `one`（仅整数 1）/ `other` |
| ru / uk | `one` / `few` / `many` / `other` |
| ar | `zero` / `one` / `two` / `few` / `many` / `other`（六类别） |
| cs / sk | `one` / `few` / `many` / `other` |
| pl | `one` / `few` / `many` / `other`（mod 10/100 规则） |

## 五、RTL（从右到左）

RTL 由语言集合判定（`ar/he/fa/ur/ps/sd/ug/yi/ckb`），切换 RTL 语言后 `NovaTheme.isRtl/direction`
联动更新。组件适配双轨：

1. **声明式镜像**（QML 原生）：容器挂 `LayoutMirroring.enabled: NovaTheme.isRtl`，
   Row/anchors.left/right 自动翻转——首选方案，零手工布局。
2. **逻辑侧/物理侧分离**（手动布局组件）：凡手工算 x 的组件，提供 `effectiveSide`
   （RTL 时 left↔right 互换）或布局期判定 `isRtl` 反排——
   `NovaDrawer`/`NovaLayout`（effectiveSide）、`NovaSlideItem`（loader 镜像 + 物理键互换）、
   `NovaPagination`（箭头字符取反）、`NovaBreadcrumbs`（反排重布局）。

> 原则：**逻辑侧语义恒定**——RTL 下 `NovaSlideItem.slideLeft()` 仍是"把面板滑到逻辑左侧"，
> 物理方向自然镜像；测试以物理坐标断言镜像结果。

## 六、日期格式化

`style` 支持命名样式（`shortDate / longDate / shortTime / longTime / shortDateTime / longDateTime / iso`）
或直接传 Qt 自定义 pattern（如 `"yyyy-MM-dd"`）。

> **坑位 43**：Qt 6.12 的 `Qt.formatDate` 三参重载实际不存在（`(date, locale, pattern)` 被解析为
> 两参版、pattern 丢弃）。自定义 pattern + locale 必须走 `Qt.locale(name).toString(date, pattern)`。
